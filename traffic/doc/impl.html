NORDstat implementation notes

The system consists of several separate parts. These are documented separately, and they are:

  • The traffic poller
  • The plot scripts
  • The load-map script
  • The tabular report HTML scripts
  • The common support perl code

There is a common list of outstanding issues in the TODO list.

I will admit that much of the code has been "grown" bottom-up, and in places this is clearly visible, in that not all parts are as elegant and well-designed as they possibly should be.
