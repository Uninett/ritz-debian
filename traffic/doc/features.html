NORDstat features

This package has the following main features:
  • The amount of work to maintain the setup is attempted kept at a minimum. This means "no per-port configuration work" apart from setting up the port on the router. For this to work well, the operators of the network need to adhere to certain conventions when configuring the individual router ports.
  • There are three main entry points to the statistics, a clickable graphical map showing the circuit loading with colour codes, zoomable plots for the individual ports, and an entry point to tabular reports covering various time periods. (The references here lead to "live" examples of these features.)
  • Implemented using freely available tools; uses TCL, Scotty, perl (version 5), gnuplot (beta version), GD library etc. See the list of tools for a complete list and pointers to the tools used to implement this package.
  • CGI script results written to be cacheable, and in most cases sensible HTTP Expires headers are emitted to control cache expiration of documents returned.
  • Most scripts emit sensible ALT= tags so that it is possible to use lynx to look at the statistics.
