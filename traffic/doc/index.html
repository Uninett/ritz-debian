NORDstat documentation

This is a quick first attempt at writing up some minimal documentation for the NORDUnet/UNINETT router traffic statistics package which I've decided to call NORDstat. This package contains a poller which collects router port statistics from MIB-II's interfaces group (and from cisco's private extentions), and a set of scripts for post-processing the data and scripts to present the data via a WWW interface.
