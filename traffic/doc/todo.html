NORDstat TODO list

This is a non-exhaustive list of things to fix in and/or things to add to this package.

  • The traffic poller should record restart events on all ports right after it starts. (Otherwise the backend scripts might lack information about a reset of the counters.)
  • The error messages from the poller should be handled better. They probably should not be logged directly to a file. Use the "syslog" command instead?
  • Find (and fix) bug (in scotty (?)) which sometimes causes poller to stop, stuck in blocking recvfrom(). This would remove the need for the nanny.pl script.
  • Redo configuration file syntax, introduce "region tags", make it possible to filter tabular reports by region tag.
  • Write script summarizing new ports added and removed ports for each day.
  • Add help document for datespec format.
  • Document conventions for cisco description field format.
  • Let load-map show other data than percentage load?
  • Let load-map have references to other maps.
  • Let load-map get "zoom out" and "previous" and "next" period imagemap areas.
  • Make base map for load-map time-dependent (as the physical setup will change over time).
  • Make a cleaner split between the front-end and the back-end of the load-map, making it easier to add an interpreter for a new drawing format.
  • Make load-map interpret the tgif drawing format (since the xfig file easily becomes cluttered and hence difficult to maintain, it looks more promising with tgif).
