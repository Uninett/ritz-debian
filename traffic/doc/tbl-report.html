Tbl-report implementation

The script in cgi/tbl-report.pl implements the handler for the HTML form in html/tbl-report.html.

This script is mostly table-driven, and produce a HTML layer on top of the daily/weekly/monthly reports. References to relevant plots are inserted into the resulting HTML code.

The scripts used to produce the periodic reports are all located in the report/ directory.
