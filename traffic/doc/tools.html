NORDstat prerequisites

This package was built using the following publically available tools. Note that some of the tools are now available in newer versions; I have no reason to beleive that any of the newer tools wouldn't work.

  • Perl version 5.003 or later.
  • CGI.pm Perl module for writing cgi-bin scripts in Perl5. This module may be included in Perl version 5.004.
  • Gnuplot 3.6beta, configured to use the GIF driver.
  • GD library for gif driver in gnuplot.
  • The GD perl module to draw GIF images from Perl5.
  • TCL version 7.5p1. TCL 7.6 may also work, but a minor patch to scotty is required in that case.
  • Scotty version 1.2.4, version 1.2.5 will also work.
  • Apache web server.
  • Berkeley Make as found in NetBSD. You also need the NetBSD MK files to go with Berkeley Make, this should be installed in a directory Berkeley Make itself uses (defined in pathnames.h in the source distribution).
  • The Xfig drawing tool.
  • The transfig conversion package.
  • The snmpnetstat TCL/scotty program.
  • The tgif program may be used later by this package.
  • The tkmapedit TK-based imagemap edit program. (This is no longer needed, but it looks useful just the same.) A set of local diffs to tkmapedit is available.
